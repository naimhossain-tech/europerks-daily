# EuroPerks Daily Website

A simple responsive static website for EuroPerks Daily.

## Publish with GitHub Pages
1. Create a GitHub repository named `europerks-daily`.
2. Upload `index.html`, `style.css`, and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main`, folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

Expected URL: `https://naimhossain-tech.github.io/europerks-daily/`

## Before publishing
- Edit `index.html` and replace the Facebook link `href="#"` with the real public EuroPerks Daily Facebook Page URL.
- Confirm that all descriptions accurately represent your page.
- Only add real affiliate links when you have joined the relevant programs. Do not invent offers or prices.
- This site is a promotional landing page, not a guarantee of any discount or offer.
